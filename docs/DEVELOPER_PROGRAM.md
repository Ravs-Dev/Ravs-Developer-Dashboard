# GitHub Developer Program preparation

RAVS Developer Dashboard uses the GitHub REST API for profile, public repository, Pull Request search, Actions workflow run, and release data.

## Evidence to prepare

- A stable deployed HTTPS URL that loads without requiring maintainer-only access.
- A working GitHub OAuth connection using the published callback URL.
- A support inbox monitored by the maintainer and displayed in the product footer.
- A public source repository with setup instructions, scope explanation, and security policy.
- Screenshots or a short walkthrough showing the integration working with actual GitHub data.

## Before submitting or updating program details

1. Verify that the app is deployed and its OAuth App homepage/callback URLs match the deployment.
2. Verify that the support email is a real inbox and can receive messages.
3. Confirm that the OAuth scopes requested are still least-privilege for the features that ship.
4. Review the current [GitHub Developer Program documentation](https://docs.github.com/en/integrations/concepts/github-developer-program). Requirements and profile highlights are controlled by GitHub and can change.

This project is a technical starting point; it does not guarantee acceptance, program status, or a Developer Program Member highlight.
